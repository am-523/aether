# Aether — Market Intelligence Platform

A high-end, immersive SaaS landing page crafted with modern web standards, featuring atmospheric video visuals, smooth inertial scrolling, a sticky glassmorphic navigation bar, and an enterprise product dashboard showcase.

## ✨ Features

- **Cinematic Atmospheric Hero**: Background looping video (`bgvideo.mp4`) with subtle dark vignette overlay and seamless fallback.
- **Sticky Glassmorphic Navbar**: Centered floating pill with high-blur backdrop filter that smoothly docks and deepens on scroll.
- **Harmonious SaaS Spacing**: Balanced, high-converting flow from headline, subtitle, and CTA actions directly into the product preview.
- **Enterprise Dashboard App**: Medium-sized, high-DPI SaaS dashboard card with macOS window controls, live status indicators, interactive telemetry pins, and a full-resolution lightbox viewer.
- **Smooth Inertial Motion**: Integrated with [Lenis](https://lenis.darkroom.engineering/) for 60fps smooth scrolling and [GSAP](https://greensock.com/) for micro-interactions.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or newer recommended)
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/am-523/aether.git

# Navigate into the project folder
cd aether

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Build production bundle
npm run build

# Preview production build
npm run preview
```
